# Rebuttal Reference Cases

Use these cases to learn workflow structure, concern grouping, response ordering, tone, and compression. Do not reuse their facts, claims, results, reviewer wording, or manuscript locations in another rebuttal.

## InFuse — complete three-stage case

- `infuse/01-raw-reviews.docx`: original reviews arranged by reviewer; authoritative source for verbatim quotations.
- `infuse/02-grouped-concerns.docx`: author-curated cross-reviewer concern grouping, including positive comments.
- `infuse/03-rebuttal.docx`: 924-word final response organized by shared concern.

Useful patterns: moving shared main-text/supplement concerns together, distinguishing computational contribution from system integration, combining reviewer labels in headings, and using quantitative layer-by-layer evidence.

Important caution: the grouped file includes occasional editorial framing and split source paragraphs. Treat the raw review file—not the grouped file—as the quote authority when checking verbatim fidelity.

## SimpliX — partial two-stage case

- `simplix/02-grouped-concerns.docx`: cross-reviewer concern grouping prepared before response drafting.
- `simplix/03-rebuttal.docx`: 993-word final response.

The original reviewer-by-reviewer source file is not included. Therefore this case cannot validate Step 1 quote fidelity and must not be represented as a complete three-stage example.

Useful patterns: prioritizing 3D validation and baseline comparisons, grouping repeated mixed-dimensionality concerns, stating planned analyses precisely, and fitting many technical responses close to 1000 words.

Important caution: several statements are future commitments rather than completed results. Learn the organization, but keep planned work visibly distinct from verified evidence in new tasks.

## Maintaining the library

Add each future case in its own lowercase folder. Prefer this naming:

- `01-raw-reviews.<ext>`
- `02-grouped-concerns.<ext>`
- `03-rebuttal.<ext>`

Register the case here, state whether all three stages are present, give the final word count, and record any evidence or quote-fidelity caveats. Preserve source files unchanged.
